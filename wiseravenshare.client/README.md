# WiseRavenShare Client

Frontend application for WiseRavenShare, built with React + Vite.

## Prerequisites

1. Node.js 20+
2. npm 10+

## Local development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173`.

## API base URL

- Configure `VITE_API_BASE_URL` to point to your backend.
- If unset during local Vite dev, the client defaults to `http://localhost:10000`.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
